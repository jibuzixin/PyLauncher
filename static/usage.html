WHY

解决了什么痛点

手动流程 每次重复

  • cd 进入脚本目录
  • 回忆参数名、值、默认值
  • 手敲一长串运行命令
  • 盯终端输出、翻找结果文件

  • 参数表单自动解析，必填项标红置前

HOW IT WORKS

运行原理：本质就是拼一条命令

所有「智能化」都在帮你正确拼出下面这条命令，并在脚本所在目录执行它：

STEP 1
参数表单
你填 --input a.csv --retry 3
→
STEP 2
拼接命令
后端按环境生成可执行命令
→
STEP 3
在脚本目录执行
cwd = 脚本所在目录
→
STEP 4
实时输出
WebSocket 流式回显到终端
# 有 uv 时 cd /path/to/script_dir && uv run python tool.py --input a.csv --retry 3 # 无 uv 但有 .venv 时（等价） cd /path/to/script_dir && .venv/bin/python tool.py --input a.csv --retry 3

界面里的「运行命令」条会实时显示最终命令，点右侧图标即可复制；点开还能手动改写，改写后只刷新参数段、保留你改过的前缀。

REQUIREMENTS

载入的脚本要符合什么约定

1 · 必须用 argparse 解析命令行参数 唯一硬性约定

启动器靠它自动识别参数名、类型、默认值与描述。不满足也能导入，但参数无法自动识别。

python tool.py --input a.csv --retry 3

2 必填 / 可选判定

  • 声明 required=True 的标 *
  • 位置参数自动排在最前
  • 其余视为可选

3 类型与布尔

  • type=int/float → 数字输入框
  • choices=[...] → 下拉选择
  • store_true → 界面开关
  • nargs / append → 逗号分隔多值

4 描述信息

  • help="…" 显示在输入框上方
  • 脚本描述显示在卡片上
  • 两者都能在界面里再编辑

5（可选）PEP 723 内联依赖

  • 单文件工具在文件头声明依赖
  • uv 直接运行，无需 requirements
  • 卡片上会标 PEP 723 标记

FEATURES

核心功能一览

脚本卡片墙

搜索、标签筛选、收藏、运行中 / 失败筛选，卡片直接显示参数个数与上次运行结果。

参数抽屉

点卡片从右侧滑出抽屉：环境状态、依赖文件、预设、参数表单、运行命令一次看全。

参数预设

保存 / 覆盖 / 固定 / 上下排序预设，一键复写表单；填过的参数会自动暂存，下次打开还在。

实时终端

每次执行开一个独立 tab，支持 \r 单行进度条、ANSI 颜色、单行复制、拖选批量复制、自动滚动与手动接管。

命令行导入

粘贴一条历史命令，自动拆解成参数并回填表单；缺失 / 未知 / 类型错误的参数会明确列出。

执行历史

状态、时间、耗时、退出码、完整输出、标签；支持多选批量删除、一键重跑、复制原命令。

定时任务

cron 表达式或可视化点选构建，支持参数预设、执行次数上限、到期自动停用、立即运行。

环境管理

检测 uv / conda / mamba、扫描本机已有虚拟环境并一键切换，或手动指定任意路径的环境。

局域网访问

顶栏开关切换后服务自动重启，同网段设备可访问；请只在可信网络开启。

SHORTCUTS & TIPS

快捷操作与小技巧

  • ⌘ + Enter / Ctrl + Enter：运行当前脚本
  • Esc：关闭弹窗 / 命令编辑条 / 复制浮标
  • 脚本名称与描述：直接点文字就能改，失焦自动保存
  • 定时任务的 cron 与次数上限：直接在卡片上改，失焦保存；Enter 提交，Esc 撤销
  • 执行记录里的 ✕：点两次才真正删除，第一次会亮黄条并 3 秒倒计时
  • 终端里选中若干行，会浮出「复制选中 N 行」按钮
  • 底部终端可拖高、可折叠；勾掉「自动滚动」后回看历史不会被新输出顶走
  • 标签既写在脚本上，也写在执行记录上，两边都能增删
