Why

解决了什么痛点

以前跑一个脚本工具，每次都是同样的重复动作：

✕ 手动流程（每次重复）

  • cd 进入脚本目录
  • 回忆参数名、值、默认值
  • 手敲 uv run 一行长命令
  • 盯终端输出、翻找结果文件
  • 跑完就忘：没记录、没对比
→

✓ 本工具（一次配置，以后一键）

  • 脚本列表点击即选，自动定位目录
  • 参数表单自动解析，必填置顶
  • 点「运行」= uv run，参数自动拼好
  • 控制台实时输出，行号可复制
  • 每次执行自动留痕，可重跑可复盘
How it works

运行原理：本质就是拼一条 uv run 命令

所有"智能化"都在帮你正确拼出下面这条命令，并在它所在的目录执行：

1
参数表单--input a.csv --retry 3
→
2
拼接命令uv run python 脚本.py …
→
3
脚本目录执行cwd = 脚本所在目录
→
4
实时输出终端流式回显
# 实际执行的命令（可在界面复制）；有 uv 走 uv run，无 uv 自动改用 .venv/bin/python
cd /path/to/script_dir && uv run python tool.py --input a.csv --retry 3
# 无 uv 时等价于： cd /path/to/script_dir && .venv/bin/python tool.py --input a.csv --retry 3

uv 轨道（推荐）

uv venv 创建 → uv pip install 装依赖 → uv run --project <目录> python 脚本.py

原生 Python 轨道

python -m venv .venv → .venv/bin/python -m pip install → .venv/bin/python 脚本.py（Win 为 Scripts\python.exe）

依赖隔离 兼容 pyproject 单脚本 PEP 723 无 uv 也能运行
Requirements · 脚本要求

载入的脚本要符合什么约定

1
必须用 argparse 解析命令行参数启动器靠它自动识别参数名、类型、默认值与描述 —— 这是唯一硬性约定。python tool.py --input a.csv --retry 3
2
必填 / 可选判定声明了 required=True 或带默认值的为必填，排在表单最前；其余视为可选
3
类型与布尔通过 type=int/float 识别数字类型；action="store_true" 的布尔开关在界面显示为开关按钮
4
描述信息参数 help="…" 会自动显示在输入框上方，可再编辑；脚本描述显示在卡片与表单区
5
（可选）PEP 723 内联依赖单文件工具可在文件头声明依赖，uv 直接运行，无需 requirements 文件
Prerequisites · 前提条件

需要什么前提条件

运行环境二选一（满足其一即可）：装了 uv，或本机有 Python 能创建虚拟环境。

方案 A：安装 uv（推荐）

macOS：brew install uv；Windows：irm https://astral.sh/uv/install.ps1 | iex

方案 B：原生 Python + venv

不装 uv 也行：python -m venv .venv 建环境、venv 的 pip 装依赖、venv 的 python 运行，全部自动兼容

脚本遵循约定

使用 argparse 解析参数（见上一页）。不满足也能导入，但参数无法自动识别

# 方案 A（有 uv）：页面自动走 uv 轨道
# 方案 B（无 uv 但有 .venv）：页面自动走原生轨道，无需 activate
初始化: python -m venv .venv  →  依赖: .venv/bin/python -m pip install -r requirements.txt
运行: .venv/bin/python 脚本.py  （Windows 用 Scripts\\python.exe）

Features

核心功能一览

参数预设

保存/覆盖/固定常用预设，一键复写表单，自动保存当前字段

实时控制台

终端流式输出（含 \r 进度条）、行号复制、自动滚动、多任务并行

执行历史

每次执行自动留痕：状态、参数、完整输出、标签，可重跑可删除

定时任务

cron 表达式或可视化点选，支持执行次数、参数预设、到期自动停用

Data & Network

数据与访问

本地 SQLite 存储

脚本信息、预设、执行记录、定时任务全部存在本地 launcher.db，不联网、不泄露

局域网访问（可选）

顶栏「局域网」开关：打开后同网段设备可访问；关闭则仅本机。请只在可信网络开启

# 启动 / 停止（一键脚本，无需 kill）
macOS: 双击 start.command / stop.command   Windows: 双击 start.bat / stop.bat
# 访问地址
本机 http://127.0.0.1:8900   局域网 http://你的IP:8900
