Python 脚本启动器 · 使用说明

本地脚本运行平台 —— 把「进入目录 + 敲 uv 命令 + 盯终端输出」变成可视化表单 + 一键按钮。
v0.0.48

1快速开始

右上角 「导入 / 扫描」 是你的入口：

  • 导入单个脚本：填写 .py 文件路径（或本地文件选择器），自动解析命令行参数；可自定义脚本名称与描述
  • 扫描目录：扫描指定目录下的全部 .py 文件，逐个导入
  • 导出 / 导入 JSON：顶栏可批量导出全部脚本信息，用于版本迁移，导入即可恢复

约定：脚本必须使用 argparse 解析命令行参数，启动器才能自动识别参数、默认值、类型与描述。

2三栏布局

  • 左侧 · 脚本列表：搜索、标签过滤（多选）、运行任务徽章（黄色 ●N，点击查看运行中任务并跳转详情）
  • 中间 · 参数表单：当前脚本的环境状态、参数预设、参数填写与执行
  • 右侧 · 面板：控制台 / 执行记录 / 定时任务 三个页签

侧栏与面板之间可以拖拽分隔条调整宽度，宽度偏好自动保存；顶栏左上角可收起/展开侧栏。

3参数表单

  • 必选参数置顶：有默认值或声明 required=True 的视为必填，排在最前
  • 类型标签：每个参数显示类型（strintfloatbool…），带颜色区分
  • 描述：解析到的参数描述显示在输入框上方，可点击编辑
  • 布尔参数：使用开关按钮切换
  • 自动保存：填写内容实时保存，下次打开还在；「仅显示已填参数」开关可隐藏空值
  • 参数预设：保存当前字段为预设、覆盖已有预设、固定常用预设置顶、最近使用排序，标签过多时折叠为「更多」

4执行与环境（uv）

运行原理：在脚本所在目录使用 uv run python 脚本.py 参数…，每个脚本独立虚拟环境。

  • 环境检测：打开脚本时自动检测 uv 是否存在（绿色=就绪）、虚拟环境是否已创建
  • uv 未安装：给出友好提示与 Mac / Windows 安装命令
  • 初始化环境：点击「初始化 venv」创建虚拟环境；自动识别 requirements.txt / pyproject.toml，也可手动指定依赖文件路径安装
  • 单脚本运行：兼容 PEP 723 内联依赖脚本（文件头 # /// script 声明），uv 可直接运行，无需依赖文件
  • 复制命令：执行按钮旁可复制当前参数对应的完整 uv run 命令

5控制台

  • 实时展示终端标准输出，支持 \r 进度条同行刷新 等终端效果
  • 行号：每行显示行号，悬浮出现复制按钮，可复制整行；支持多行选择复制
  • 自动滚动 / 等宽字体：工具栏开关控制
  • 同时运行多个任务时，每个任务可在执行记录详情页查看自己的实时输出；脚本卡片徽章实时显示运行中的任务数
  • 「终止」按钮终止最新一次运行（SIGTERM → 强杀进程组）

6执行记录

  • 每次执行自动记录：脚本、参数、开始时间、退出码、状态（成功失败运行中已终止）、完整标准输出
  • 添加标签：给记录打标签便于筛选；支持按标签 / 脚本名 / 状态搜索
  • 详情：点击记录滑入详情页（运行中任务实时输出 + 终止 / 复制命令 / 用此参数重跑 / 删除），左上角返回
  • 多选删除：进入「多选」模式批量删除，也支持 hover 单条删除
  • 「重跑」会将该次执行的参数回填到表单

7定时任务

  • cron 表达式：兼容标准 5 段 cron（分 时 日 月 周），如 */10 * * * *
  • 可视化选择：不懂 cron 也能点选分钟 / 小时 / 每天 / 每周等常用规则
  • 执行次数：卡片上直接编辑次数（输入 -1 表示不限次数），达到次数自动停用；再次启用时从 0 重新计数
  • 参数填充：任务可使用某个参数预设，也可自行填写
  • 卡片实时显示下次执行时间（精确到分钟）；可随时编辑 cron 与次数

8数据与存储

所有数据保存在本地 launcher.db（SQLite）：脚本信息、参数预设、执行记录、定时任务、界面偏好。随删随恢复，无需联网。

服务地址：http://127.0.0.1:8900；访问时 URL 带 ?t=时间戳 可绕过浏览器缓存加载最新版本。

9常见问题

Q：怎么让局域网内其他设备访问？
  • 启动脚本默认已监听所有网卡（--host 0.0.0.0），其他设备访问 http://你的局域网IP:8900（终端 ifconfig / ipconfig 查 IP）
  • macOS 首次监听可能弹出「允许传入网络连接」，需允许；Windows 防火墙需放行 8900 端口（TCP）
  • 安全提示：监听所有网卡意味着同一局域网内任何设备都能打开页面并运行你的脚本，请只在可信网络使用；临时只想本机使用可执行 python main.py --host 127.0.0.1
Q：uv 未安装怎么办？
页面会给出对应平台的安装命令：macOS brew install uv；Windows winget install astral-sh.uv 或 pip install uv。
Q：导入脚本提示 422？
422 表示参数校验失败：请检查路径是否为绝对路径、文件是否存在，且脚本为可解析的 Python 文件。
Q：服务怎么启动 / 停止？
项目根目录提供一键脚本，无需手动 kill 进程：
  • macOS 启动：双击 start.command —— 首次运行自动创建虚拟环境并安装依赖；服务后台常驻，关闭窗口不影响使用；若服务已在运行则只打开浏览器
  • macOS 停止：双击 stop.command —— 自动结束监听 8900 端口的服务进程
  • Windows 启动：双击 start.bat —— 自动建环境装依赖后前台运行
  • Windows 停止：双击 stop.bat —— 自动结束监听 8900 端口的服务进程
